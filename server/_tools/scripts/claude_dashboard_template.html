Context budget

Token map

Area = estimated tokens. Grouped by component → owner → file, colored by when the file loads. Click a cell to filter the files table to it.

Path simulator

Type a path Claude would read or edit. Shows the path-scoped rules that load for it, the skills CLAUDE.md's "Skills by where you work" table asks for, and the total context that adds up to.

Skills

Listing = the name + description every session carries. Body = SKILL.md without frontmatter, loaded on invoke. Supporting = reference files read on demand. Lint comes from building-skills/scripts/validate_skill.py.

Rules

Each paths: glob with the number of project files it matches today (.gitkeep placeholders excluded). A path-scoped rule with 0 matches never loads.

Hooks & permissions

From .claude/settings.json. Hooks cost no context unless they print; they run on every matching tool call.

Issues

Broken links and backtick paths, skill lint findings, rules that match nothing, and skills missing from or named in CLAUDE.md's skill table.

Files

Every file under .claude/. Click a header to sort. Code share = fraction of characters inside fenced code blocks.
